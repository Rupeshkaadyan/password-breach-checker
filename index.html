Password Breach Checker

Find out if your password has appeared in a known data breach.

✓ Privacy-first: your password is hashed in your browser and never sent. Only the first 5 characters of its hash leave the device.
How this stays private. When you check a password, your browser computes its SHA-1 hash, then sends only the first 5 characters of that hash to the HaveIBeenPwned database. The server returns every hash that starts with those 5 characters; the match is done locally in your browser. Your password — and its full hash — never leaves your device. This is the standard "k-anonymity" method.
This checks whether a password appears in known breach corpora. It does not measure password strength. Stay safe with a password manager: Bitwarden · 1Password.
Data source: HaveIBeenPwned Pwned Passwords (free, public range API). This tool stores nothing and makes no other network calls. Open the source, run it offline, verify it yourself.
